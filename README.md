# tatabahasa-melayu

เว็บไซต์เอกสารประกอบการสอนรายวิชา **0113131 ไวยากรณ์ภาษามลายู** (*Tatabahasa Bahasa Melayu* / Malay Grammar)
สาขาวิชาภาษามลายู คณะมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยทักษิณ · ภาคเรียนที่ 2 ปีการศึกษา 2569

## สิ่งที่มีในเว็บ

- ปกนอก (เปิด–ปิดได้) ปกใน และสารบัญ
- แผนการเรียน 15 สัปดาห์ และบทเรียน 13 บท แต่ละบทมี 6 ส่วน: ผลลัพธ์การเรียนรู้ (OBE) · โครงร่าง · เนื้อหาสาระสำคัญ · กรณีศึกษา · คำถามท้ายบท · เอกสารอ้างอิง
- ข้อปรนัยท้ายบทตรวจคำตอบอัตโนมัติ และแนวคำตอบกรณีศึกษาแบบกดเปิดดู
- แบบทดสอบรวม สุ่มข้อจากภาควจีวิภาค (บทที่ 1–7) ภาควากยสัมพันธ์ (บทที่ 8–13) หรือทุกบท
- เครื่องมือฝึก: เติมปัจจัย meN- peN- ber- ter- อัตโนมัติ และแปลงประโยคกรรตุวาจกเป็นกรรมวาจก
- อภิธานศัพท์ไวยากรณ์ภาษามลายู–ไทย ค้นหาได้
- กดคำภาษามลายูตัวเอียงเพื่อฟังเสียง (ใช้เสียงอ่านของเบราว์เซอร์) · ใช้บนมือถือได้ · มีโหมดมืด
- โทนสีแดงเลือดหมู–ทอง ลายซองเก็ตบุหงากันจิก (แยกจากเว็บวิชา 0001154 ที่เป็นโทนน้ำเงิน–ขาว)

## วิธีแก้ไขเนื้อหาบทเรียน

เปิดไฟล์ใน `content/` บน GitHub กดไอคอนดินสอ แก้ข้อความ แล้วกด **Commit changes** เว็บจะอัปเดตภายในประมาณ 1–2 นาที

ไฟล์เขียนแบบ Markdown:

- `## ` = หัวข้อหลัก 6 ส่วนของบท (ห้ามลบหรือสลับลำดับ)
- `### ` = หัวข้อย่อย
- `*คำ*` = ตัวเอียง (ใช้กับคำภาษามลายู จะกดฟังเสียงได้) · `**คำ**` = ตัวหนา
- ตาราง: `| หัว 1 | หัว 2 |` ขึ้นบรรทัดใหม่ `|---|---|` แล้วตามด้วยแถวข้อมูล
- `(แนวคำตอบ: ...)` ท้ายบรรทัด จะถูกซ่อนเป็นปุ่ม "ดูแนวคำตอบ"

ข้อปรนัย (ใต้หัวข้อ `### ก. ปรนัย`) ต้องเขียนตามรูปแบบนี้ ระบบจึงตรวจคำตอบได้:

```
1. คำถาม
   ก. ตัวเลือก ข. ตัวเลือก ค. ตัวเลือก ง. ตัวเลือก

**เฉลย** 1 ข · 2 ง
```
